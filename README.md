# Sistema de Votación

Proyecto desarrollado de forma individual.

## Funciones

1. **Registrar voto** — emite un voto, validando que un votante no vote dos veces.
2. **Ver resultados** — muestra el conteo con porcentajes.
3. **Reiniciar votación** — limpia votos y guarda historial en historial.json.
4. **Mostrar ganador** (mejora adicional) — indica quién ganó.
